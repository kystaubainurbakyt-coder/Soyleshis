# SOYLE

Қазақ тілін үйренуге арналған Flutter мобильді және Web қосымшасы.
Интерфейс: **орысша / ағылшынша**. Қазақша — үйренетін тіл.

## Іске қосу

Flutter 3.41+ / Dart 3.11+:

```bash
flutter pub get
flutter run -d chrome --web-port=7357
```

Мобильді құрылғы үшін `flutter run` қолданыңыз. Браузердегі бұрынғы аккаунттар
сақталуы үшін сол браузерді, адресті және портты пайдаланыңыз. Web сақтау HTTPS/localhost қажет етеді.
Жоба жаңартылғаннан кейін қосымшаны толық тоқтатып қайта іске қосыңыз.

## Интерфейс және оқу

RU/EN ауыстырғышы кіру бетінде және негізгі оқу экрандарында бар; баптаулардан да өзгертіледі.
Тіл таңдауы құрылғыда сақталады. Интерфейс ауысқанда аккаунт, оқу нәтижесі және енгізілген
кіру деректері жоғалмайды. Сабақтарда қазақша түпнұсқа және тек таңдалған тілдегі аударма көрсетіледі.
Түсіндірме, сұрақ, кері байланыс, батырмалар және сертификат таңдалған тілде беріледі.

Каталогта 75 сабақ:

| Курс | Сабақ |
|---|---:|
| A1 | 30 |
| A2 | 15 |
| B1 | 12 |
| B2 | 10 |
| C1 | 8 |

Әр сабақта тақырыпқа арналған грамматикалық түсіндірме, екі аудармасы бар алты контекстік фраза,
төрт репликалық диалог, қолдану мысалдары, ауызша/жазбаша өзіндік жұмыс және сегіз сұрақ бар.
Фраза конструкторында сөздердің ретін жинап тексеруге болады. Ашық жазбаша жұмыстарға автоматты баға қойылмайды.
Өзгермейтін сабақ нөмірлері бұрынғы негізгі сабақ нәтижелерін сақтауға мүмкіндік береді.

Оқушы сабақтарды қарайды, іздейді, сақтайды, қайталайды және жаттығулар орындайды.
Сабақ қосу/өңдеу формалары оқушы қосымшасынан алынып тасталған; `/editor` маршруты да ашылмайды.
Жарияланған каталог `List.unmodifiable` арқылы тек оқуға беріледі.
Бұрын аккаунтта сақталған жеке сабақтар жарияланған оқу бағдарламасын алмастырмайды.

## Редакторға арналған жергілікті админ-панель

Жобаның `soyle` папкасында:

```bash
python tool/admin_server.py
```

Терминалдағы толық `http://127.0.0.1:8766/#...` сілтемесін браузерде ашыңыз.
`#` белгісінен кейінгі бір реттік токен каталогты оқу мен өзгертуді рұқсаттайды.
Сілтемені басқаға бермеңіз. `Ctrl+C` панельді тоқтатады; жаңа іске қосуда токен өзгереді.

Бұл — жоба иесінің осы компьютерде жұмыс істейтін редакторы. Ол интернетке жарияланбайды
және оқушы аккаунтынан әкімші құқығын бермейді. Ортақ серверлік admin/login жүйесі қосылмаған.
Панельде деңгей бойынша қарау, жаңа сабақ қосу, атауларды, екі тілдегі түсіндірмені,
қазақша фразаларды және аудармаларын өңдеу бар.

Сақтағанда мазмұн толықтығы тексеріледі; каталог пен Flutter дерегі жаңартылады.
Алдыңғы нұсқа `assets/curriculum/.backups/` ішіне сақталады.
Өзгерісті қосымшаға шығару үшін Flutter-ды толық қайта іске қосыңыз.

- Негізгі редакцияланатын дерек: `assets/curriculum/catalog.json`.
- Flutter дерегі: `lib/features/lessons/data/curriculum_data.dart`.
- JSON-нан қайта генерациялау: `python tool/build_curriculum.py`.
- `--import-source` — бастапқы авторлық мәтінді қайта импорттау; панельдегі кейінгі өзгерістерді алмастырады.

## Нәтижелер және сертификаттар

Сабақ кемінде 75% дұрыс жауаппен аяқталады. Бірінші өтуге 100 XP, алғаш 100% алуға 25 XP беріледі.
Үздік нәтиже төмендемейді; қайта өтуден қайталама XP берілмейді. Сәтті қайталау оқу сериясына есептеледі.
Карточкаларда 12 бірегей фраза қайталанады; толық аяқталғанда күніне бір рет 20 XP беріледі.
Күндік мақсат — 100 XP, барлық курс аяқталғанда — 20 XP.

Әр деңгейдің барлық негізгі сабақтары аяқталғанда жеке сертификат беріледі.
Аты-жөн, деңгей, берілген күн, сабақ саны, орташа балл және тұрақты нөмір сақталады.
RU/EN PDF нұсқасын жүктеуге/бөлісуге болады. Бұл — SOYLE ішкі курсының сертификаты,
сыртқы аккредитация немесе серверде тексерілетін CEFR біліктілік құжаты емес.
Бұрынғы қысқа курс сертификаттары деректе архивтеледі; кеңейтілген курс сертификатын автоматты ашпайды.

## Аккаунт және сақтау

Алдымен тіркелу қажет. Email пішімі, бос өрістер, 6–128 таңбалық пароль,
үлкен әріп және парольді қайталау тексеріледі. Қайталама email қабылданбайды.
Бес сәтсіз кіруден кейін 30 секундтық шектеу бар. Жабық маршруттар қонаққа ашылмайды.
Парольдер salt + PBKDF2-HMAC-SHA256 (600 000 айналым) түрінде secure storage ішінде сақталады.

Аккаунт, прогресс, таңдаулылар және марапаттар құрылғыға жергілікті сақталады.
Шығу нәтижелерді өшірмейді. SQL, ортақ аккаунт сервері, email растау және құрылғылар арасында синхрондау жоқ.

## Дизайн және код

Қою көк/бейтарап палитра, Noto Sans мәтіні және Noto Serif сертификаты қолданылады.
Қаріптер қосымшада бар; OFL лицензиялары `assets/fonts/` ішінде.
Кіру анимациясы, ауысатын карточкалар, прогресс анимациясы, жұмсақ айналдыру және scrollbar стилі қосылған.
Қозғалысты азайту параметрі негізгі кіру және сұраққа қайту анимацияларында ескеріледі.

`lib/app` — іске қосу/маршруттар; `core` — Theme, локализация, күй және validation;
`features` — auth, lessons, home, profile, progress, review; `shared/widgets` — ортақ компоненттер.
Бұрынғы Figma файлы соңғы кеңейтілген бағдарламаны толық көрсетпейді. Соңғы UI суреттері `docs/previews/` ішінде.

редактордың оқушыдан жабылуын, A1–C1 каталогын, XP/сертификат шарттарын және PDF жіберуді қамтиды.
Экрандар 320×568, 390×844, 844×390 және 1024×768 өлшемдерінде, шағын экранда 130% мәтінмен тексеріледі.

## Практикалық жұмыс №4 — Hive

Оқу каталогы, профиль, прогресс, таңдаулылар және жеке оқу жазбалары Hive CE қорында сақталады. Профиль → «Мои заметки / My notebook»: қосу, оқу, өзгерту, растаумен өшіру, мәтін бойынша іздеу, деңгей/сабақ/таңдаулы бойынша сүзгілеу, атау/уақыт/маңыздылық бойынша сұрыптау. Сабақ ішінен сол сабақтың жеке жазбаларын ашуға болады. Ескі прогресс пен таңдаулылар алғаш ашылғанда көшіріледі.

Модельдер мен байланыстар: [docs/local_data_model.md](docs/local_data_model.md). Құпиясөздер бұрынғыдай secure storage ішінде қалады.
