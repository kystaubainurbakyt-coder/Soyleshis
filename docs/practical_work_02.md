# Практикалық жұмыс №2 — SOYLE

Мақсаты: қазақ тілін үйренетін пайдаланушының мобильді сценарийлерін әзірлеу.

## 1. Жоба және визуалды стиль
Flutter демо қосымшасы және өңделетін Figma дизайны дайын.
Figma: [SOYLE — Қазақ тілін үйрену](https://www.figma.com/design/XjZKx0htqVh3Ud1WHpQ1fY).
Беттер: 01 · Design System; 02 · Screens & Prototype. Барлығы 21 экран мен күй, өлшемі 390 × 844.
Негізгі frame: 390 × 844; көлденең шегініс 24; аралықтар 8/16/24/32.
Стиль: ашық фон, дөңгеленген карточкалар, қазақша қысқа мәтіндер, Material белгішелері.

## 4. Design System
Қайта қолданылатын код: AppTheme, PrimaryButton, LessonCard, AppNavigation.
Батырма: биіктігі 58, радиусы 20; негізгі әрекет — қою көк фон, ақ мәтін.
Енгізу өрістері: ақ фон, радиусы 16, label және қате мәтіні.
Карточка: ақ фон, радиусы 22, белгіше және қысқа сипаттама.
Навигация: Басты / Сабақтар / Іздеу / Таңдаулы / Профиль.
Figma компоненттері үшін күйлер: default, pressed, disabled; input үшін empty, filled, error;
таңдаулы үшін selected/unselected. Flutter стандартты Material күйлерін пайдаланады.

## 5. Экрандар мен байланыстар
| Экран | Әрекет → нәтиже |
|---|---|
| Splash | 2.5 секунд → Login |
| Login | тіркелген email және дұрыс құпиясөз (≥6 таңба, үлкен әріп) → Home; тіркелу → Registration; танысу → Onboarding |
| Onboarding 1–3 | Келесі → келесі қадам; соңғы қадам / өткізу → Login |
| Registration | аты + email + құпиясөз + растау → Home; аккаунтым бар → Login |
| Home | Оқуды бастау → List |
| List | карточка → Detail; + → Create; іздеу / деңгей → сүзілген тізім |
| Detail | жүрек → таңдаулы күйі; өңдеу → Edit; жаттығуда ≥75% → жетістік; профиль → Profile |
| Create/Edit | тексерілген өрістерді сақтау → алдыңғы экран; кері → сақтаусыз қайту |
| Search | сөз/атау/аударма және деңгей → нәтижелер; карточка → Detail |
| Favorites | сақталған сабақтар; карточка → Detail; бос күй көрсетіледі |
| Profile | жетістік саны; таңдаулы → Favorites; баптаулар → Settings; шығу → Login |
| Settings | атты сақтау → Profile; еске салғыш демо ауыстырғышы |

Негізгі сценарий: Splash → Login → Home → List → Detail → Сабақты аяқтау → Profile.
Қосымша сценарийлер: тіркелу; 3 onboarding қадамы; сабақ құру/өңдеу; іздеу; таңдаулыға қосу/алу; профиль атын өзгерту; шығу.

## 6. Figma дизайны және прототип
[Дизайнды ашу](https://www.figma.com/design/XjZKx0htqVh3Ud1WHpQ1fY?node-id=5-1085).

1. 01 · Design System: түстер, айнымалылар, Roboto мәтін стильдері, компоненттер және олардың күйлері.
2. 02 · Screens & Prototype: Splash, Login, Registration, 3 Onboarding, Home, List, Detail,
   аяқтау нәтижесі, Search, Favorites, Profile, Settings, Create/Edit және қате/бос/таңдаулы күйлер.
3. Барлық экрандар мәтін, Auto Layout, вектор және компонент даналары ретінде өңделеді.
4. Splash 2.5 секундтан кейін Login-ге өтеді. Негізгі батырмалар Navigate to арқылы байланыстырылған.
5. Еске салғыш Switch компонентінде Off ↔ On интерактивті ауысуы бар.
6. Қарау: 02 бетін ашу → Splash frame-ын таңдау → Present ▶.
7. Негізгі сценарий: Splash → Login → Home → List → Сәлемдесу → Сабақты аяқтау → Профиль.

Тексеру: негізгі сценарийдің барлық 6 өтуі құрылымдық тексерістен өтті; жоқ destination анықталмады.
Экрандардың негізгі мазмұнында шекарадан шығу табылмады. Экрандар мен компоненттер суреті қаралды;
тізімдегі артық аралықтар ықшамдалды, Жаңа сабақ батырмасы алғашқы көрініске шығарылды.
Бұл тексеру Present режимін пайдаланушының қолмен басып өтуін алмастырмайды.

Figma — алдын ала берілген үлгі деректері мен экран күйлері бар визуалды прототип.
Өрістерде еркін мәтін енгізу, нақты аккаунт жасау және деректерді сақтау Flutter демосынан бөлек;
Figma прототипіндегі өтулер үлгі сценарийді көрсетеді. Негізгі үлгі сабақ — Сәлемдесу.
LoginError күйін тексеру үшін сол frame-ды жеке Present арқылы ашуға болады.
Техникалық дәлелдер: figma-state.json, figma-screens-state.json, figma-qa.json.

## 7. Жаңартылған Flutter нұсқасы
Тіркелмеген немесе қате құпиясөз енгізген адам кіре алмайды. Email пішімі, @ және домен тексеріледі.
Пароль кемінде 6 таңба, бір үлкен әріппен, бос орынсыз болуы керек; тіркелуде растау қажет.
Қайталама email қабылданбайды. Аккаунттар secure storage ішінде, парольдер salt пен PBKDF2 хэші түрінде сақталады.
5 қате әрекеттен кейін 30 секундтық жергілікті шектеу бар. Қорғалған маршруттар тек кірген пайдаланушыға ашылады.

10 сабақтың әрқайсысында шолу, түсіндірме, 3 қолдану мысалы, сөздік, 4 репликалық диалог және жаттығу бар.
Жаттығу кемінде 75% болса ғана сабақ аяқталады; үздік балл, таңдаулылар мен сабақ өзгерістері аккаунтқа бөлек сақталады.
Басты экран: келесі сабақ, нақты оқу барысы, A1/A2 бағыттары, күнделікті өмірге арналған сабақтар және күн сөзі.
Әліпби сабағына пайдаланушы берген YouTube сілтемесі қосылды.

SQL және сервер қолданылмайды. Аккаунт тек осы құрылғыда жұмыс істейді; email иелігін растау және басқа құрылғыға синхрондау жоқ.
Еске салғыш — демо баптау; жүйелік хабарлама жіберілмейді. Create/Edit бірінші сөзді өзгертеді, қалған сөздер сақталады.
Figma алдыңғы экран сценарийін көрсетеді. Соңғы авторизация мен толық оқу мазмұны Flutter қосымшасында іске асырылған.
Тексеру: flutter analyze; flutter test --concurrency=1; flutter build web.
