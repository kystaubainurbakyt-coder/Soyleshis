# Практикалық жұмыс №5 — REST API интерактивті прототипі

## Таңдалған API

`https://jsonplaceholder.typicode.com` — посттар ресурсын оқу және CRUD сұрауларын көрсетуге арналған тест API. Жазу сұраулары демо үшін ғана орындалады: сервердегі бастапқы деректер тұрақты өзгермейді. Қосымша CRUD нәтижесін аккаунтқа байланған Hive кэшінде ұстап, келесі GET нәтижесімен біріктіреді.

## Endpoint-тер

| HTTP әдісі | Endpoint | Операция | Қолданылған код |
|---|---|---|---|
| GET | `/posts?userId=1` | Посттарды алу, JSON-ды `RemotePost` модельдеріне түрлендіру | `RemotePostApi.getPosts` |
| POST | `/posts` | Жаңа пост жіберу, `201` жауабын өңдеу | `RemotePostApi.createPost` |
| PUT | `/posts/{id}` | Пост тақырыбы мен мәтінін толық өзгерту | `RemotePostApi.updatePost` |
| DELETE | `/posts/{id}` | Постты өшіру | `RemotePostApi.deletePost` |

## Күй және жергілікті сақтау

- Сұраулар `async`/`await` арқылы орындалады; әдепкі timeout — 10 секунд.
- Экран `LinearProgressIndicator` арқылы жүктелу күйін көрсетеді.
- Сәтті CRUD операциялары хабарламамен расталады.
- Сервер қатесі, желінің болмауы, timeout, жарамсыз JSON және басқа HTTP сұрау қатесі жеке өңделеді.
- Желі қатесінде бұрын Hive-та сақталған, ағымдағы аккаунтқа тиесілі посттар көрсетіледі.
- `localId`, `ownerId`, API `serverId`, тақырып, мәтін және синхрондау күйі `soyle_v4_remote_posts` қорабында сақталады.
- JSONPlaceholder POST/PUT/DELETE өзгерістерін серверде тұрақты сақтамайды. Сондықтан интерфейс жергілікті өзгерістерді сақтап, келесі GET нәтижесіне біріктіреді.

REST экраны «Менің жазбаларым» экранының бұлт белгішесі арқылы ашылады.
