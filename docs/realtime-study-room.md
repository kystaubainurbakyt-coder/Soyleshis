# SOYLE: әкімші панелі және нақты уақыттағы оқу чаты

## Іске қосу

1. Жоба бумасында Python тәуелділіктерін орнатыңыз: `python -m pip install -r requirements.txt`.
2. Бірінші терминалда `python tool/admin_server.py` пәрменін орындап, терминалды ашық қалдырыңыз. Сервер әкімші панелін `http://127.0.0.1:8766` мекенжайында, ал WebSocket чатын `ws://127.0.0.1:8767` мекенжайында іске қосады.
3. Екінші терминалда `flutter run -d chrome --web-port=7357` пәрменін орындаңыз.
4. Қосымшада **Profile → Study room** бетін ашыңыз. Чатқа жазылған хабар басқа ашық клиенттерге бірден тарайды.
5. Әкімші панеліне кіру үшін Study room ішіндегі **Administrator sign in** сілтемесін басыңыз. Әдепкі оқу жобасының құпиясөзі — `soyle26`; ол `tool/.admin-password` файлында сақталады.
6. Әкімші панелі орысша және ағылшынша жұмыс істейді. Сабақтарды көру, қосу, өзгерту, жою және чатқа хабарландыру жіберу мүмкіндігі бар. Каталог жаңартылғанда резервтік көшірмесі жасалады.

Құпиясөзді ауыстырған соң серверді қайта іске қосыңыз: серверді тоқтату үшін `Ctrl+C`, қайта қосу үшін `python tool/admin_server.py` орындаңыз.

Қызметтер тек осы компьютердің `127.0.0.1` адресінде тыңдайды. Сервер тоқтаса, чат Offline күйін көрсетіп, сервер қайта қосылғанда байланысқа қайта қосылуға тырысады.

## Тексеру

```powershell
flutter analyze
flutter test --concurrency=1
python -m unittest discover -s tool -p "test_*.py"
```

Realtime хабына арналған Python тесттері хабар тарату, тарихты қайта жіберу, тарих көлемінің шегі, қате хабарламаларды қабылдамау және жылдамдық шектеуін тексереді. Әкімші тесттері кіру рұқсатын, логиннің шектелуін, сабақ CRUD операцияларын және хабарландыруды тексереді. Flutter-де чат хабарламасының моделі мен WebSocket күйіне арналған unit тесттер бар.

## Ескерту

Бұл оқу жобасының әкімші панелі тек жергілікті сабақ каталогын және хабарландыруларды басқарады. Тіркелген оқушылардың есептік жазбалары жергілікті құрылғыда сақталғандықтан, оларды орталықтан әкімшілендіру функциясы бұл нұсқада жоқ.
