# Авторизация және сабақтар — тексеру нәтижесі

- `flutter analyze`: ескерту/қате жоқ.
- `flutter build web`: release жинағы сәтті жасалды.
- `flutter test test/auth_service_test.dart`: 6 тест өтті.
- `flutter test test/widget_test.dart`: 5 тест өтті.
- `flutter test tool/capture_previews_test.dart`: 390 × 844 өлшемінде 5 экран көрінісі шығарылды, layout қателері жоқ.
- `flutter build apk --debug`: тексеру тоқтады — осы ортада Android SDK табылмады.

Авторизация тесттері тіркелмеген аккаунтты, қате парольді, қайталама тіркелуді,
email/пароль талаптарын, уақытша шектеуді және парольдің ашық мәтінде сақталмайтынын тексереді.
Сақтау тесті аккаунттан шығып қайта кіруді және екі аккаунт деректерінің оқшаулануын тексереді.
Оқу сценарийі кіруден бастап сабаққа, жаттығуды орындауға және профильге дейін өтеді;
қате жауаптармен сабақ аяқталмайтыны және жаттығуды қайта орындау тексерілген.

Native құрылғылардағы Keychain/Keystore интеграциясы бұл ортада тексерілген жоқ.
Widget/unit тесттері secure storage платформасының жадтағы тест нұсқасын пайдаланады;
парольді туындату алгоритмі нақты PBKDF2 нұсқасымен тексерілген.
Figma макеті бұрынғы визуалды сценарийді көрсетеді; бұл өзгерістер Flutter нұсқасына енгізілді.
